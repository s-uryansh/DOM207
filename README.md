# DOM207 Projects

### Minor Project - 1
> Foodie India MP1 is a data-driven restaurant business analysis project for the DOM207-DOM3007-DOM6401 course. Using 365 transaction records, it examines bill amounts, service periods, party sizes, per-head spending, tipping patterns,data-quality issues, and differences between weekday and weekend dining. The project delivers a formal management report, verified statistical results, decision-focused visualizations, and five reversible recommendations covering weekend lunch expansion, weekday lunch value, small-party seating, responsible tip-policy use, and improved future data collection.
